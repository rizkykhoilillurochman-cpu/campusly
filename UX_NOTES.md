# Campusly UX baseline

- Mobile navigation order: Beranda, Jadwal, Tugas, Kalender, AI, Menu.
- Every non-home page has a visible Kembali action.
- Global search supports Enter, a visible Cari action, and live suggestions across tasks, notes, schedule, agenda, and grades.
- Developer identity is one compact strip at the bottom of the Menu content.
- AI image generation is intentionally removed; the remaining AI tools are chat, scan soal, makalah, and PPT.
- AI mode is forwarded by the production gateway so paper/ppt/translate prompts no longer fall back to chat mode.
- No legacy overlay, patch, or duplicate runtime is introduced.
